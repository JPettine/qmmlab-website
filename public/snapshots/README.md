# Snapshot images

Place home-page Research Snapshots carousel images in this folder.

Use names that begin with the matching research entry stem, followed by `_snapshot_`, followed by your own label and an allowed image extension. Examples:

- `questions1_snapshot_lattice.png`
- `questions2_snapshot_phases.jpg`
- `approaches1_snapshot_modes.webp`

Allowed image formats are `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`, and `.svg`.

No binary placeholder images are committed here; add the real snapshot images manually when ready.
